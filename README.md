# LokiDarts

A personal darts project, currently in alpha. Nexus handles games, players,
training and statistics; Vision connects camera-based dart detection to your game.

This repository contains **public installer releases and feedback only**.
Application source code and development history remain private.

## Downloads

Find published alpha builds under [Releases](https://github.com/CompulsivelyCleanCarnage/LokiDarts-Releases/releases).
Downloads are public and do not require a GitHub account. If no release is listed,
the first public build is still being prepared.

- **Windows x64:** Windows 10 22H2 or Windows 11. Run the EXE as your normal user.
- **Linux x64:** Fedora 44 only. Download the RPM, its manifest, `SHA256SUMS`, and
  `install-lokidarts.sh` into one folder, then run `bash install-lokidarts.sh`.
  Fedora dependency installation needs Internet access.

Release assets come directly from the existing LokiDarts installer pipelines,
with their original filenames and checksum files. Stop LokiDarts and back up your
profile before upgrading. Alpha builds may contain bugs and breaking changes.

## Feedback

Use [Discussions](https://github.com/CompulsivelyCleanCarnage/LokiDarts-Releases/discussions)
for suggestions, questions and bug reports. A GitHub account is needed to post.
Include your platform, release version and steps to reproduce. Do not post
passwords, pairing tokens, private configuration or unreviewed logs.

LokiDarts is a hobby project made primarily for friends and family. Thanks for
trying it and sharing what you find.
